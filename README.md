# PulseBoard

PulseBoard 是一个原创的静态网页前端项目，适合作为个人作品集、GitHub Pages 展示页或前端练习项目。

作者：Gala

## 功能

- 响应式仪表盘布局
- 项目进度、专注计时、时间线和快速笔记模块
- 明暗主题切换
- 无需安装依赖，直接打开 `index.html` 即可运行

## 本地预览

双击 `index.html`，或在项目目录启动一个静态服务器：

```bash
python -m http.server 5173
```

然后访问 `http://localhost:5173`。
